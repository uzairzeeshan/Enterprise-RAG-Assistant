# Enterprise-RAG-Assistant
• Engineered an enterprise-grade multi-source RAG Assistant using Python, FastAPI, ChromaDB, and Streamlit, enabling document search and contextual Q&A across PDF, DOCX, PPTX, CSV, and Web URLs. 

• Developed a hybrid retrieval and reranking pipeline combining dense vector embeddings and BM25 sparse retrieval, with Reciprocal Rank Fusion (RRF) and Cross-Encoder reranking to improve retrieval relevance and generate answers with verifiable inline source citations.

• Implemented production-grade security and governance using JWT authentication, Role-Based Access Control (RBAC), security audit logging, and Docker Compose for containerized deployment.
